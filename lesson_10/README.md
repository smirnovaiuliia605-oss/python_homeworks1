# Документация проекта
## Описание базового синтаксиса записи и форматирования
1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов.

---

## Инструкция по запуску тестов для формирования отчета Allure
1. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите тесты с генерацией отчета Allure:
   ```bash
   pytest --alluredir=./allure-results
   ```
   Эта команда запустит все тесты и сохранит результаты в директорию `./allure-results`.
---
## Инструкция по просмотру сформированного отчета Allure

1. После завершения тестов, чтобы просмотреть отчет, выполните команду:
   ```bash
   allure serve ./allure-results
   ```
   Эта команда запустит локальный сервер и откроет отчет в браузере.

2. В отчете Allure вы увидите:
   - **Название теста**: `Поверка функциональности калькулятора с задержкой`.
   - **Описание теста**: `Тест проверяет функциональные возможности калькулятора: установку задержки, ввода выражения '7+8=', получение результата '15'`.
   - **Шаги теста**:
     - Открыть страницы калькулятора.
     - Установить задержку 45 секунд.
     - Ввести выражение 7+8=.
     - Получить результат.
     - Вывести на экран результат 15.
   - **Результат**: Отображение резьтата на экране калькулятора 15.

   - **Название теста**: `Оформление заказа в интернет-магазине.`
   - **Описание теста**: `Тест проверяет оформление заказа на странице интернет магазина: авторизацию на главной странице, добавление товара в корзину, переход на страницу оформления заказа, заполнение формы с личными данными, проверку итоговой суммы заказа.`
   - **Шаги теста**:
     - Открыть страницу интернет-магазина по ссылке.
     - Пройти авторизацию: ввести стандартные имя пользователя и пароль.
     - Добавить товары в корзину.
     - Перейти к оформлению заказа.
     - Заполнить обязательные поля: имя, фамилия, почтовый индекс.
     - Проверить итоговую сумму.
   - **Результат**: Отображение итоговой суммы 58.29.
